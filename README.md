# Análisis de ventas con Excel

Proyecto personal simulado de análisis de datos realizado con Microsoft Excel.

## Qué se hizo

- Limpieza de datos.
- Tratamiento de pedidos duplicados.
- Normalización de nombres y ciudades.
- Cálculo de ventas brutas, descuentos y ventas netas.
- Cálculo de unidades vendidas y ticket promedio.
- Creación de tablas, indicadores y gráficos.

## Herramientas

- Microsoft Excel

## Nota

Los datos utilizados son ficticios y el proyecto fue creado con fines de aprendizaje y portafolio.
